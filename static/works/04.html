ストップウォッチ

- URL https://fujikurah.github.io/stopwatch/

概要

TypeScriptでストップウォッチを作成しました。
右のボタンをクリックすると計測を開始し、再度クリックすると一時停止、さらにクリックすると再開します。左のボタンをクリックすると計測を停止し、表示時間をリセットできる仕様にしています。

使用技術

TypeScript
HTML / CSS
Vite

工夫した点・取り組み

TypeScriptの学習を目的として制作しました。
値が未定義の場合はユニオン型で型定義するなど、型定義の精密さ？を学びました。

TypeScriptの学習を目的として制作しました。
undefined の可能性がある値にはユニオン型を用いるなど、型安全性を意識した実装を行いました。

また、当初は計測時間を「分・秒・ミリ秒」の3つの変数で管理していましたが、処理が複雑になっていたため、計測時間を1つの変数に統一し、表示時に分・秒・ミリ秒へ変換する形へ改善しました。これにより、状態管理をシンプルにしつつ、保守しやすい実装を意識しました。
