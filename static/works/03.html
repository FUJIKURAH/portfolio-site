カレンダー

- URL https://fujikurah.github.io/calendar/

概要

TypeScriptでカレンダーを作成しました。
初期表示では当月のカレンダーを表示し、前月・翌月の日付は薄いグレーで表示しています。
また、カレンダー上部の矢印アイコンをクリックすることで、前月・翌月へ切り替えられるようにしました。

使用技術

TypeScript
HTML / CSS

工夫した点・取り組み

TypeScriptの学習を目的として制作しました。
JavaScriptでの実装と大きな違いはないと感じましたが、変数や関数の引数・戻り値に型を定義することで、値の扱いをより意識しながら実装できました。

特に、前月・翌月の日付の値と表示数を取得するロジックの実装に苦戦しました。
カレンダーの1週目・最終週の空きを埋めるため、Dateオブジェクトを用いて月末日や曜日を取得し、必要な日付数を計算して表示しています。
